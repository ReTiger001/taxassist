# 税务智能知识助手 —— 功能介绍

> 一个**在本机运行**的税务政策检索与判断工具。
> 把国家税务总局与 31 个省级税务局的公开政策收进一台电脑，判定每份文件的现行效力，并让全文与附件都可检索。

---

## 一、它解决什么问题

查政策不难，难的是三件事：

| 难在哪 | 本站怎么做 |
|---|---|
| **文件散在 32 个站点**，总局与各省各查一遍 | 一处检索：标题 / 文号 / 发文机关 / 正文 / 关键词一起搜，可按地区、栏目、效力、年份筛 |
| **不知道哪份还有效** | 逐条判定效力（现行有效 / 已废止 / 尚未生效），**每条都写明依据** |
| **正文藏在附件里**，搜索搜不到 | PDF / Word / Excel / 压缩包内的正文解析入库，参与全文检索 |

## 二、核心能力

### 1. 一处检索（14,000+ 份文件）

- **数据规模**：13,946 条政策；32 个地区源站；66,000+ 条引用与废止关系；3,275 份已解析附件
- **相关度排序**：标题命中优先于正文兜底；也可只按条件浏览、不输关键词
- **英文也能搜**：输入 `VAT`、`stamp duty` 等英文税种词，自动对照成对应中文术语检索

### 2. 效力判定，且依据可溯

每条结论都标注**它凭什么**：

| 标记 | 含义 |
|---|---|
| **官方标注** | 政策原文自带时效标注，或官方废止目录点名 —— 最硬的一档 |
| **据他文判定** | 另一份文件写明废止了它；依据原文可在详情页看到 |
| **未发现废止** | 库内没有任何文件说它废止。**这不等于官方确认有效** |

### 3. 税务助手（本机大模型）

丢一份合同、方案或一个想法进去，对照政策库给出四节报告：

**合规判断 → 适用政策 → 优化空间 → 风险与待确认**

- 每条结论都标依据编号，依据卡片可点回政策原文
- 依据的效力标签**取自政策库，不由模型生成**（模型会改写效力状态，这一块不采信它的文字）
- 推理全程在本机（qwen2.5:14b），不联网、不外传

### 4. 中英双语

界面与数据值全部支持中英切换；首次访问跟随浏览器语言。

### 5. 程序接口

- **MCP 接口**：供 Claude Desktop / Cursor 等 AI 客户端直接调用（`search_policies` / `get_policy` / `lookup_by_doc_no` / `kb_overview`）
- **HTTP 接口**：本机 JSON 接口，默认只读

## 三、数据边界（重要）

**全部政策原文、译文、判定与附件都保存在本机，不上传任何第三方。**

服务默认只监听 `127.0.0.1`；需要外部访问时经自建隧道（HTTPS）。

## 四、必须说清的局限

1. **「未发现废止」不等于「官方确认有效」** —— 它只表示库内没有废止证据。政策库不可能收全所有废止公告，**重要事项请核对原文**。
2. **施行日期覆盖约六分之一**（实测 1939/13717 ≈ 14%）—— 多数政策正文确实没写具体施行日期，这一项已接近原文可提取的上限。
3. **译文为机器翻译**，仅供理解参考，不具备法律效力。

## 五、适合谁用

- 需要**频繁查政策原文并确认时效**的税务、财务、法务人员
- 需要对合同 / 方案做**初步税务合规扫描**的团队
- 想把政策库**接进自己的 AI 工作流**（MCP / HTTP 接口）

## 六、怎么用

| 方式 | 命令 / 地址 |
|---|---|
| 网页 | 浏览器打开 `http://127.0.0.1:8765` |
| 命令行检索 | `taxassist search 研发费用加计扣除` |
| 库自检 | `taxassist kb --selftest` |
| 本机 JSON 接口 | `taxassist kb`（默认 8767） |
| AI 客户端接入 | `taxassist mcp` |
