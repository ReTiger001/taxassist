## 一、我们提供什么

《税务智能知识助手》是一套**政策检索、效力追踪与合规初筛**的服务。具体包含：

1. **政策库** —— 收录国家税务总局与 29 个省级税务局的**公开政策文件**，
   历史全量自 1984 年起，每日增量更新。
2. **效力判定** —— 对每份文件给出效力状态（现行有效 / 已废止 / 尚未生效），
   并注明依据。依据分三档，可逐条核对（见第五节）。
3. **全文与附件检索** —— 标题、文号、发文机关、正文、关键词一起检索；
   PDF / Word / Excel 附件中的正文解析后同样参与检索。
4. **税务助手** —— 提交业务事实（合同、方案、想法），产出带原文依据的
   四节分析：合规判断 → 适用政策 → 优化空间 → 风险与待确认。
   结论的依据指向库内原文，可点开核对；**效力标签取自政策库，不由模型生成**。
5. **每日政策简报** —— 当日新增与变动的政策清单。
6. **程序接口** —— HTTP API 与 MCP，便于接入你自己的系统或 AI 工作流。

## 二、我们不提供什么

为避免误解，以下事项明确**不在**服务范围内：

- **不提供税务、法律或投资意见。** 我们提供的是资料的检索、整理与效力线索；
  任何对外出具的结论，都应由执业人员核对原文后自行作出专业判断。
- **不保证收录完整。** 见第六节。
- **不代理**任何与税务机关的申报、沟通或提交事项。
- **不保证译文的法律效力。** 译文为机器翻译，仅供理解参考。

## 三、数据与隐私

### 3.1 两种部署形态

| | 托管使用 | 私有化部署 |
|---|---|---|
| 服务运行位置 | 本方自有设备（**不经过任何第三方云平台**） | 你方的服务器或内网 |
| 政策数据 | 在本方设备 | 在你方环境 |

| 更新方式 | 本方每日更新后同步 | 同上（可选择离线更新包） |
| 适用 | 一般使用 | 有内网合规要求、或需与内部系统打通 |

### 3.2 托管形态下，你的数据去了哪里

| 数据 | 处理方式 | 留存 |
|---|---|---|
| 助手提交的业务事实（文字） | 仅用于当次分析 | **不写入政策库** |
| 上传的文件（合同、表格等） | 解析出文本后，**原始文件立即从磁盘删除** | 解析出的文本暂存于本方服务设备，用于当次分析 |
| 检索关键词与调用记录 | 用于检索与用量核对 | 用量记录保留，供双方对账 |
| 账号与口令 | 只存口令的 scrypt 哈希（连本方也无法还原你的口令） | 合作结束后删除 |

**不外传第三方**：助手分析在本方自有设备的本地模型上完成；除抓取公开政策
文件外，服务不向外部发送你的任何数据。你的上传解析文本可**随时要求删除**，
合作结束时一并删除。

### 3.3 关于「数据不出本机」的准确含义

本方在项目设计上有一条硬性边界：**客户的业务资料只进本地代码与本地模型**，
不粘贴进任何公网 AI 服务。请注意这一条的边界：它约束的是**本服务的数据流向**；
你方人员自行把资料交给本服务之外的任何工具，不在本约束范围内。

  等于接口声称的总数**；不等则记录为「不完整」并告警、触发补抓 ——
  **漏抓会被发现，不会被静默忽略**。
- **可自证**：每个抓取页面按页归档原始响应（gzip）；如对某条数据的来源有疑问，
  可回溯"当时官方返回的就是这些"。

## 五、效力判定怎么读

| 标记 | 含义 | 强度 |
|---|---|---|
| **官方标注** | 政策原文自带时效标注，或官方废止目录点名 | 最硬的一档 |
| **据他文判定** | 另一份文件写明废止了它；依据原文在详情页可查 | 较强 |
| **未发现废止** | 库内没有任何文件说它废止 | **不等于官方确认有效** |

官方时效标注的实际填充率很低（实测样本约 2%），因此缺失时我们不会默认"有效"，
而是进入待人工确认队列。

## 六、已知局限（请务必读完）

1. **「未发现废止」不等于「官方确认有效」。** 它只表示库内没有废止证据。
   任何政策库都收不全所有废止公告，重要事项请核对原文。
2. **施行日期覆盖约六分之一**（实测 1,939 / 13,717 ≈ 14%）。多数政策正文
   本身就没写施行日期 —— 这一项已接近原文可提取的上限。
3. **译文为机器翻译**，仅供理解参考，不具备法律效力。
4. **收录有边界**：见第四节（河北、青海异常；部分动态栏目未接入）。
   我们每日运行并告警补抓，但不承诺 100% 收全。
5. **原文准确性以官方来源为准。** 本服务是对公开信息的整理，若与官方发布
   不一致，以官方为准。
6. **助手输出为初筛性质。** 它是分析辅助，不是结论；见第二节。
